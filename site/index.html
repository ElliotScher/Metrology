Untangling every unit of measurement

On paper, the world measures with one system. The SI defines seven base units, and since 2019 each one is set by fixing the value of a physical constant. In practice, many other systems are still in use. Imperial and US customary units share names but not sizes. CGS has three incompatible variants. Natural units set chosen constants to 1, and astronomy, radiology, navigation and computing each keep units of their own. Even within SI, some conventions are still argued over, such as whether an angle has a dimension.

This project aims to untangle all of it, one unit at a time. For each unit it records what the unit is built from, every formal definition it has had, and how it relates to other units. The graph is arranged in levels. Level 0 holds the units defined directly from constants of nature. Every other unit sits one level below the deepest unit it's built from, so you can trace any unit upward to the constants it ultimately rests on. Click a unit to see its full history.
